# Hybrid-Utility-Simulation-Sheets-
A HOMER Pro configuration model and case study optimizing a South African 50MW Solar PV + 40MWh BESS hybrid plant. Evaluates PVsyst AC/DC generation curves against Eskom Megaflex Time-of-Use tariffs to resolve midday inverter clipping constraints and manage battery state-of-charge degradation over a 25-year lifecycle.
